# getforTrip OTA — Flight Search & Filter Audit Report

## 1. 개요 및 P0-02 결함 원인 분석
항공권 검색 및 발권 시스템은 실시간 좌석 등급(Fare Basis), 유류할증료/공항세 계산, 왕복 스케줄 페어링이 복합 결합된 고난도 도메인입니다.

### 기존 결함 원인 (Root Cause)
1. **과거 정적 일자 하드코딩 (`11/01 (오늘)`)**:
   - 상단 날짜 탭이 2026년 또는 과거의 고정된 문자열로 박혀 있어 사용자가 다른 날짜를 선택하거나 유동적인 최저가를 탐색할 수 없었음.
2. **왕복 여정 2단계 선택 불가**:
   - 왕복 검색 시 가는 편(Outbound)과 오는 편(Inbound)을 독립적으로 선택하지 못하고 단일 리스트에서 끝나는 결함 존재.
3. **결과 0건 빈 화면 출력**:
   - API 응답 실패 시 폴백 메커니즘 부재로 검색 결과 0건 안내와 함께 먹통 발생.

## 2. 해결 및 아키텍처 개선

### 2.1 다이나믹 7일 최저가 스트립 엔진 (`generateDynamicDateStrip`)
- 사용자가 선택한 기준 출발일(Dep Date)을 중심으로 앞뒤 3일(총 7일)의 날짜를 계산.
- 각 날짜별 최저가 운임(`min_price_krw`)을 동적으로 산출하여 상단 캘린더 스트립에 렌더링.
- 사용자가 스트립의 날짜를 클릭하면 해당 일자의 항공 스케줄로 즉시 전환됨.

### 2.2 2단계 왕복(Round-Trip) 스케줄 선택 플로우
- **1단계 (가는 편 선택)**: 
  - 서울/인천(ICN) → 도쿄/나리타(NRT) 구간 항공편 리스트 표시.
  - 고객이 원하는 스케줄 선택 시 상단에 선택된 가는 편 카드 요약 표시.
- **2단계 (오는 편 선택)**:
  - 뷰가 자동으로 '오는 편 선택' 상태로 전환되며 반대 방향(NRT → ICN) 귀국 항공편 리스트 표시.
  - 귀국 항공편까지 선택 완료 시 총 결제 예상 금액 계산 및 결제창(`/flights/booking`)으로 이동.

### 2.3 패싯 필터 및 운임 브랜드 (Fare Brands)
- **항공사 필터**: 대한항공(KE), 아시아나항공(OZ), 제주항공(7C), 타이항공(TG), 에어프랑스(AF) 선택.
- **경유 여부**: 직항(Direct), 1회 경유 필터.
- **출발 시간대**: 오전(06:00~12:00), 오후(12:00~18:00), 야간(18:00~24:00) 필터.
- **운임 브랜드**:
  - `Standard`: 기본 위탁 수하물 15kg, 변경 수수료 발생
  - `Flex`: 위탁 수하물 23kg, 일정 무료 변경 1회
  - `Business`: 전용 체크인, 비즈니스 라운지 이용, 32kg 위탁 수하물 2개
