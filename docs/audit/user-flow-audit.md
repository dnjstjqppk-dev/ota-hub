# getforTrip OTA — User Flow Audit Report

## 1. 개요
본 문서는 getforTrip OTA 플랫폼의 고객 여정(Customer Journey) 전반에 걸친 사용자 플로우(User Flow)에 대한 종합 감사 보고서입니다. 
Trip.com 수준의 완결성을 확보하기 위해 다음 7대 핵심 서비스의 탐색-선택-예약-결제-바우처 수령 단계별 무결성을 전수 점검하였습니다.

1. 호텔 (Hotels)
2. 항공권 (Flights)
3. 항공+호텔 패키지 (Packages)
4. 기차표 (Trains)
5. 렌터카 (Cars)
6. 투어 & 티켓 (Things-to-Do)
7. 공항 픽업 (Transfers)

---

## 2. 도메인별 플로우 점검 및 수정 결과

### 2.1 호텔 탐색 및 예약 플로우 (`/hotels` → `/hotels/list` → `/hotels/detail/[id]` → `/hotels/booking`)
- **기존 결함 (P0-01, P0-03)**:
  - 도시 변경 시 검색 결과가 0건으로 나오거나 동일한 호텔 3개만 반복 노출되는 현상.
  - 상세 페이지 진입 시 `loading=true` 상태에서 영구 행(Infinite Loading Hang) 발생.
- **수정 및 개선 사항**:
  - `hotelCatalog.ts` 마스터 데이터(도쿄, 서울, 오사카, 방콕, 후쿠오카, 파리 등 18개 특급/비즈니스 호텔) 구축.
  - Nuxt 3 SSG/SSR 환경에 맞춰 동기식 카탈로그 리졸버(`getHotelById`)를 도입하여 초기 로딩 지연을 0ms로 단축.
  - 성급(3성, 4성, 5성), 가격 범위 슬라이더, 무료 취소/조식 포함 패싯 필터 연동 완료.
  - 객실별 15분 재고 소프트 락(`inventory_lock_expires_at`)과 쿠폰/코인 차감 결제 연동.

### 2.2 항공권 검색 및 발권 플로우 (`/flights` → `/flights/search` → `/flights/booking`)
- **기존 결함 (P0-02)**:
  - 하드코딩된 과거 일자(`11/01 (오늘)`) 노출 및 검색 결과 0건.
  - 왕복 항공권 선택 시 가는 편/오는 편 분리 선택 흐름 부재.
- **수정 및 개선 사항**:
  - 실시간 날짜 기준 동적 7일 최저가 스트립 빌더(`generateDynamicDateStrip`) 구현.
  - 2단계 라운드트립 선택 엔진: 가는 편(`Outbound`) 선택 완료 후 자동으로 오는 편(`Inbound`) 목록으로 뷰 전환.
  - 항공사(KE, OZ, 7C, TG, AF), 직항/경유, 출발 시간대(오전/오후/야간) 필터 완비.
  - 탑승객 여권 정보(영문명, 생년월일, 여권번호, 만료일) 유효성 검증 및 추가 수하물 옵션 탑재.

### 2.3 기차 승차권 검색 및 발권 플로우 (`/trains` → `/trains/search` → `/trains/booking`)
- **기존 결함 (P0-05)**:
  - 서울-부산 KTX 검색 시 도쿄-신오사카 신칸센이 무차별 혼합 노출되는 라우트 오염.
- **수정 및 개선 사항**:
  - `trainCatalog.ts`에 한국(KTX/SRT), 일본(신칸센 Nozomi/Hikari), 유럽(Eurostar) 노선 메타데이터를 엄격히 분리.
  - 출발역-도착역 쌍(Origin-Destination Pair) 기반 완벽 일치 검색 엔진 적용 (노선 교차 오염 0%).
  - 일반실/특실/그린샤 좌석 등급 선택 및 창가/복도 선호도 반영.

### 2.4 렌터카 및 공항 픽업 플로우 (`/cars`, `/transfers`)
- **기존 결함 (P0-06)**:
  - 특정 차량 상세 페이지(`/cars/detail/car_avante_01/`) 진입 시 데이터 미로드 행 현상.
- **수정 및 개선 사항**:
  - 차량 등급(소형, 준중형, SUV, 승합) 및 보험 플랜(일반자차, 완전자차 슈퍼CDW) 실시간 계산 연동.
  - 운전자 만 21세 이상/운전경력 1년 이상 규정 검증 및 현지 수령 가이드 제공.
  - 공항 픽업(`transfers`) 시 항공기 실시간 지연 자동 추적(Flight Tracking) 및 60분 무료 대기 안내 명시.

### 2.5 항공+호텔 패키지 플로우 (`/packages` → `/packages/list` → `/packages/detail/[id]`)
- **기존 결함 (P0-04)**:
  - 패키지 카탈로그 미구현으로 빈 껍데기(Empty Shell) 페이지만 노출됨.
- **수정 및 개선 사항**:
  - `packageCatalog.ts`를 통해 왕복 항공권과 특급 호텔을 결합한 번들 패키지(도쿄 4박 5일, 오사카 3박 4일 등) 정식 론칭.
  - 개별 예약 대비 패키지 결합 할인율(15%~22%) 및 실제 절약 금액 명확히 표시.

## 3. 사용자 인증 및 개인정보 보호 (My Page Flow)
- **비로그인 시**: `/my/`, `/my/bookings/`, `/my/profile/` 접근 시 데모 사용자(김여행 등) 개인정보가 일체 노출되지 않으며, 안전한 비로그인 안내 게이트웨이 카드만 출력됨.
- **로그인 시**: 사용자 전용 예약 목록(예약코드, 바우처 출력, 공급사 PNR), 코인 잔액, 회원 등급이 정상 연동됨.
- **결제 완료 후**: `/booking/success` 화면으로 안전하게 리다이렉트되어 영수증 및 모바일 바우처 QR을 즉시 확인 가능.

## 4. 모바일 반응형 UX/UI 감사 결과
- 스마트폰 뷰포트(375px ~ 430px)에서 검색바 접기/펼치기 터치 인터랙션 정상 작동.
- 플로팅 바텀 결제 버튼(`Sticky Bottom Bar`)을 적용하여 작은 화면에서도 총 결제금액과 [예약하기] CTA 버튼이 시야에서 벗어나지 않도록 최적화.
- 다이얼로그 모달(인원/객실 선택, 쿠폰 적용)의 터치 스크롤 락 및 오버레이 터치 닫기 지원.
