# getforTrip OTA — Admin Console Audit Report

## 1. 개요 및 운영 현황
getforTrip 관리자 콘솔(Admin Console)은 플랫폼 운영 총괄팀이 전체 주문(OMS), 공급사 재고(ARI), 회원, 정산 및 프로모션을 관리하는 내부 B2B 백오피스입니다.

- **독립 운영 구조**: 일반 고객용 웹사이트와 Cloudflare 배포 및 라우팅이 완전히 분리되어 있으며, 관리자 인증 없이는 어떠한 내부 데이터도 조회할 수 없습니다.
- **주요 관리 영역**:
  1. `/admin/` — KPI 대시보드 (총 거래액 GMV, 실시간 예약 건수, 발권 성공률, 도메인별 점유율)
  2. `/admin/bookings/` — 주문 관리 시스템 (전체 도메인 예약 내역, 상태 강제 변경, 취소/환불 승인)
  3. `/admin/hotels/` — 호텔 속성, 객실 타입 및 공급사별 재고 할당 모니터링
  4. `/admin/flights/` — 항공 노선 및 운임 베이시스(Fare Basis) 매핑
  5. `/admin/settlement/` — 파트너사별 월별 수수료 정산 및 송금 내역 승인
  6. `/admin/coupons/` — 글로벌 프로모션 쿠폰 및 타겟팅 할인 규칙 관리
  7. `/admin/users/` — 회원 권한 관리, FDS(이상 거래 탐지) 모니터링
  8. `/admin/audit-logs/` — 관리자의 모든 상태 변경 작업에 대한 불변 감사 로그

---

## 2. 주요 보안 및 무결성 감사 결과

### 2.1 접근 제어 및 세션 관리 (RBAC)
- **Role 기반 권한 분리**:
  - `SUPER_ADMIN`: 전체 시스템 설정, 정산 승인, API 키 발급 권한.
  - `OPERATOR`: 예약 상태 변경, CS 수동 발권 지원, 쿠폰 발급.
  - `FINANCE`: 정산 데이터 조회 및 세금계산서/지출결의서 관리.
- **세션 보안**:
  - 관리자 JWT 토큰은 `HttpOnly`, `Secure`, `SameSite=Strict` 쿠키로 전달되며, 세션 유효시간은 60분으로 제한.
  - 15분 이상 미활동 시 자동 화면 잠금(Screen Lock) 적용.

### 2.2 주문 관리 시스템 (OMS) 트랜잭션 무결성
- 공급사 GDS/PMS 장애로 인해 고객 결제는 성공했으나 발권이 지연된 건에 대해 관리자가 `수동 재시도(Retry)` 또는 `전액 즉시 환불(Force Refund)`을 1클릭으로 처리할 수 있는 워크플로우 구비.
- 모든 상태 변경 시 변경 사유(Reason Code) 입력을 필수로 강제하여 감사 추적성 확보.

### 2.3 정산 및 수수료 관리 (Settlement Engine)
- 공급사 계약 수수료율(기본 10%~15%)에 따라 예약 확정(체크아웃 완료 기준) 건만 자동으로 정산 원장에 집계.
- 취소 수수료 및 노쇼(No-show) 발생 시 플랫폼과 파트너 간 배분 비율 자동 계산.
