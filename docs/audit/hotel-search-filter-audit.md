# getforTrip OTA — Hotel Search & Filter Audit Report

## 1. 개요 및 P0-01, P0-03 결함 원인 분석
호텔 검색 엔진은 OTA의 최대 매출원(GMV)으로, 목적지별 실시간 가격과 객실 재고를 정확하고 빠르게 제공해야 합니다.

### 기존 결함 원인 (Root Cause)
1. **도시 검색 결과 왜곡 및 0건 노출**:
   - 기존 구현에서는 목적지 파라미터(`?destination=도쿄`)가 전달되었음에도 내부 매핑 로직 누락으로 도쿄, 서울, 오사카 등 어느 도시를 검색해도 서울 호텔 3개만 정적으로 반환하거나, 매칭 실패 시 빈 배열(`[]`)을 반환하여 0건이 표시됨.
2. **상세 페이지 영구 로딩 행 (Infinite Loading Hang)**:
   - Nuxt 3 SSG 정적 생성 시 `loading=ref(true)`로 선언되고 `onMounted` 훅 내부에서만 API 호출을 시도함. 그러나 SSG 빌더는 `onMounted`를 실행하지 않으므로 사전 렌더링된 HTML이 "호텔 정보를 불러오는 중입니다..." 스켈레톤 상태로 영구 고정되어 사용자 브라우저에서도 무한 대기가 발생함.

## 2. 해결 및 아키텍처 개선

### 2.1 마스터 호텔 카탈로그 구축 (`hotelCatalog.ts`)
- 6대 핵심 여행지(서울, 도쿄, 오사카, 방콕, 후쿠오카, 파리) 총 18개 특급 및 프리미엄 비즈니스 호텔 전수 등록:
  - 서울: 시그니엘 서울, 그랜드 워커힐 서울, 신라호텔
  - 도쿄: 신주쿠 그랑벨 호텔, 힐튼 도쿄, 그랜드 하얏트 도쿄
  - 오사카: 난바 오리엔탈 호텔, 인터컨티넨탈 오사카, 스위소텔 난카이
  - 방콕: 만다린 오리엔탈 방콕, 아난타라 시암, 더 페닌슐라 방콕
  - 후쿠오카: 하얏트 리젠시 후쿠오카, 미츠이 가든 호텔 기온
  - 파리: 리츠 파리, 르 브리스톨 파리, 호텔 드 크리용

### 2.2 검색 알고리즘 및 다단계 패싯 필터
- **도시 및 키워드 매칭**: 한글, 영문, 도시 코드(`TOKYO`, `SEOUL` 등) 완벽 대응.
- **성급 필터**: 3성급, 4성급, 5성급 다중 선택.
- **가격 범위 슬라이더**: 1박당 최소~최대 예산 필터링.
- **옵션 필터**: 조식 포함 여부(`has_breakfast`), 무료 취소 가능 여부(`is_refundable`).
- **정렬 옵션**: getforTrip 추천순, 최저가순, 평점 높은 순.

### 2.3 SSR/SSG 렌더링 안정성 확보
- 컴포넌트 셋업 시점에 `searchHotelCatalog(destination)` 동기 호출을 통해 초기 상태를 즉시 채워 넣음으로써 무한 로딩 및 0건 노출을 원천 차단함.
- `nitro.prerender.routes`에 주요 호텔 상세 경로(`/hotels/detail/htl_tokyo_01/`, `/hotels/detail/htl_seoul_01/`, `/hotels/detail/htl_osaka_01/`)를 명시하여 정적 HTML 사전 빌드 완료.
