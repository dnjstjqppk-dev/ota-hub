## 1. 파트너 허브 아키텍처 및 역할 기반 접근제어 (RBAC)

getforTrip 파트너 허브는 숙박 시설, 항공사, 렌터카사 등 제휴 공급사가 자사의 인벤토리를 관리하고 예약을 승인하며 정산 명세를 조회할 수 있는 전용 B2B 콘솔입니다.

### 1.1 회원(B2C)과 공급사(B2B)의 엄격한 세션 격리
- **일반 고객 세션 (`useAuthStore`)**: 마이페이지(`/my`), 예약 관리(`/my/bookings`), 쿠폰함 조회 권한만 부여.
- **파트너 세션 (`usePartnerStore`)**: 인가된 공급사 계정(`hotel_partner@getfortrip.com` 등)으로 로그인해야만 활성화되며, 파트너 전용 서브도메인 및 경로(`/partner/*`) 접근 허용.
- **상호 침범 방지**: 일반 고객 계정으로 로그인되어 있더라도 파트너 권한이 없으면 파트너 페이지 진입이 자동 차단됨.

## 2. 5대 파트너 관리 서브시스템 보안 및 기능 검증

### 2.1 파트너 대시보드 (`/partner/index.vue`)
- **기능**: 월간 총 매출액(Gross), 플랫폼 수수료(10%) 공제 후 실수령액(Net), 승인 대기 예약 건수, 활성 상품 수, 고객 평점 모니터링.
- **보안 조치**:
  - `partner-auth` 미들웨어 적용 완료.
  - 미인증 접속 시 매출액 및 예약 요약 데이터가 브라우저에 전송되지 않음.
  - 최근 예약 목록 내 고객 성명 비식별 마스킹(`김** (성인 2명)`).

### 2.2 상품 및 재고 관리 (`/partner/products.vue`)
- **기능**: 신규 객실 상품 등록, 판매 상태 변경(판매중/일시정지/매진), 잔여 재고 수량 실시간 가감, 판매가 대비 원가(Cost Price, 90%) 자동 계산.
- **보안 조치**:
  - 비인가 사용자의 원가 및 마진율 정보 열람 원천 차단.
  - 재고 수정 시 세션 토큰 유효성 검증.

### 2.3 예약·바우처 관리 (`/partner/bookings.vue`)
- **기능**: 상태별(전체/승인대기/확정/체크인완료/취소) 필터링, PMS 고유 예약확정번호(PNR) 입력 및 발급, 투숙객 체크인 완료 처리.
- **보안 조치**:
  - 고객 전화번호 및 이메일 전수 마스킹 (`010-****-5678`, `tr**@getfortrip.com`).
  - 비인가 상태에서 예약자 상세 모달 및 PNR 발급 기능 차단.

### 2.4 정산 및 수수료 관리 (`/partner/settlement.vue`)
- **기능**: 정산 주기(월 2회)별 총 결제액, 수수료, 실지급액, 전자세금계산서 발행 상태 조회, 정산 명세서(Excel) 다운로드, 정산 수취 계좌 확인.
- **보안 조치**:
  - 파트너사의 금융 계좌번호 및 정산 금액 보호.
  - 비로그인 접속 시 즉시 로그인 안내 화면으로 격리.

### 2.5 OpenAPI 및 웹훅 연동 설정 (`/partner/settings.vue`)
- **기능**: PMS/CMS 채널매니저 연동용 Secret Key 발급, 실시간 주문 푸시 수신 웹훅 URL 설정, 테스트 핑(Ping) 전송.
- **보안 조치**:
  - 하드코딩된 Secret Key 완전 폐기 및 난수화.
  - 기본 상태에서 키는 마스킹 처리되며, '키 복사' 또는 '재발급' 시에만 일시적 복호화.
  - 웹훅 테스트 핑 전송 시 SSRF(Server-Side Request Forgery) 방지를 위한 화이트리스트 도메인 검증.
