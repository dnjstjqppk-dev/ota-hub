# TG-20 멀티리전 + 분산 DB — 계획·수용기준 (2026-11-16)

> 백로그: [TG-20](TRIP_GRADE_BACKLOG.md) — 리전 확장 + 분산 RDBMS + DR 훈련.
> 수용: 리전 장애 시 RTO/RPO 달성 증명. 의존 TG-09·TG-13.
> 정찰: TG-09 PG 하네스(D1-shim, 스키마 이식), TG-13 SLO·`/status`·장애 기록,
> 단일 리전 Workers + D1 운영 중.

## 1. 기판 결정: 코드 완성 + 리허설 증명 (실 리전은 사용자 단계)

- 코드가 할 수 있는 것만 한다: 읽기 복제본 라우팅(R/W 분리), 리전 어피니티
  헤더, DR 런북 + 자동 DR 리허설 스크립트. **실제 2번째 리전·분산 DB
  프로비저닝은 클라우드 과금·계약이라 사용자 단계** (코드 밖 — §3).
- 수용(RTO/RPO 증명)은 스테이징 리허설로: 복제본 승격 + 트래픽 전환을
  스크립트로 재현하고 시간을 측정한다.

## 2. 범위 (v1)

1. R/W 분리: `READ_REPLICA_URL` 설정 시 읽기 쿼리 라우팅(카탈로그·검색·
   조회) + 쓰기 고정 + 복제 지연 표시(`x-replica-lag`, 임계 초과 시 primary
   폴백). 미설정 시 현재 동작 그대로 (no-op).
2. 리전 어피니티: `cf-region` 기반 라우팅 힌트 + 상태 페이지 리전 표시.
3. DR 리허설: `scripts/dr-rehearsal.mjs` (스테이징: 스냅샷→복제본 승격→
   전환→복구, RTO/RPO 측정 + 리포트) + `docs/DR_RUNBOOK.md`.
4. 백업 검증 자동화: 주간 백업 복원 테스트(격리 DB에 복원→무결성 쿼리) —
   현재 백업은 쓰기만 하고 읽어보지 않음.
5. `/status` 리전·복제본 상태 노출 + SLO에 RTO/RPO 목표 명시.

## 3. 비목표 (명시)

- 실제 2번째 리전·분산 RDBMS 프로비저닝 없음 — 사용자(매니지드 선정 후).
- 실 트래픽 전환·DNS 페일오버 실행 없음 — 리허설 + 런북까지.
- D1→분산DB 자동 마이그레이션 없음 — TG-09 경로 유지.
- 글로벌 라이트(충돌 해소) 없음 — 단일 primary 유지.

3. 백업 손상 → 복원 테스트 실패 + 알림 (표적).

## 7. 준비도 검토 (2026-11-17 구현 전, 증거 연결)

- 요구 명확성: §2 범위 5항·§4 A1-A4·§5 드릴 3종은 관측 가능하고
  충돌 없음. §3 비목표가 경계를 닫음 (실 리전·실전환 제외).
- 정찰 발견 1 (복제본 형상): D1에 읽기 복제본이 없어 DB층 분기는
  불가. 복제본 = 동일 코드 워커(HTTP)로 두고 라우터에서 허용된
  GET만 프록시한다. 쓰기는 절대 프록시하지 않는다.
- 정찰 발견 2 (부수효과): 목록·검색은 funnel 이벤트를 쓴다. 프록시
  성공 시 primary가 직접 동일 이벤트를 기록한다 (DB당 정확히 1건 —
  중복도 유실도 없음). 복제본 측은 무수정.
- 정찰 발견 3 (지연 측정): 복제본 자기보고 `x-replica-lag-ms`를
  사용. 미보고 → 0 (경계로 문서화). 임계 초과·5xx·단절·타임아웃 →
  primary 폴백 + `x-replica-fallback` + `logEvent` warn. 429는
  그대로 반환(역압 존중). 루프 가드 `X-Replica-Route`.
- 정찰 발견 4 (미설정 무변화): 복제본 미설정 시 헤더·동작 완전 동일
  (A4). 허용 목록은 비개인화 읽기만이라 인증 전달 없음.
- 정찰 발견 5 (리전): `request.cf.colo` 관측값 + `PRIMARY_REGION`
  설정값. `/status` + `x-region` 헤더로 노출. 라우팅 실체는 §3처럼
  사용자 단계.
- DR 리허설: 로컬 sqlite 복사 드릴(스냅샷→마커→복원→기동→RTO·RPO
  측정) + 보고서. 범위(로컬)를 보고서에 명시.
- 백업 검증: 덤프를 스크래치 로컬DB에 적재 후 무결성 쿼리
  (wrangler only — sqlite CLI·드라이버 불필요). 주간 잡에 복원 잡
  추가. 손상 드릴은 표적 실행.
- E2E: 서버 변수 필요라 `replica.e2e.mjs` 분리 + CI 4차 패스
  (stripe/suppliers 선례). main 스위트는 A4 무회귀.
- `wrangler.jsonc` 불변 (선례: 실값 생길 때 설정).
- 환경 실측: node v24.19.0·wrangler 4.152.0 (당일 관측).
- 연기: feature_delivery 헬퍼 미설치라 검증기 게이트는 수동 검토로
  대체 (§8 증거로 충당).
