# 부하 베이스라인 (TG-04)

> 도구: `scripts/load-baseline.mjs` (무의존성 Node 프로브. k6는 사용자 머신에
> 바이너리 추가가 필요해서 보류 — 시나리오가 필요해지면 스크립트를 k6 JS로 포팅).
> 하네스: 로컬 `wrangler dev` + fresh 격리 DB. E2E 서버와 절대 공유 금지
> (동일 IP 레이트리밋 버킷이 스위트를 오염시킨다).

## 환경

- 일시: 2026-11-14. 머신: i5-13400F · 31.8GB RAM (Windows, 로컬 wrangler dev + 격리 D1).
- 믹스: VU당 반복 — 호텔 검색 → 호텔 상세 → (10회마다) 견적 1회.

## 결과

| 런 | requests | ok | err | rps | p50 | p95 | p99 | status |
|---|---|---|---|---|---|---|---|---|
| gentle 5VU×30s | 1152 | 654 | 498 | 37.9 | 116.6ms | 290.2ms | 397.9ms | 200×600·201×54·429×498 |
| burst 15VU×30s | 1725 | 675 | 1050 | 57.1 | 170.2ms | 679.3ms | 946.7ms | 200×600·201×75·429×1050 |

## 해석·주의

- 두 런 모두 200이 정확히 600건 = 카탈로그 600/60 백스톱이 상한으로 동작한 증거.
  초과분은 429로 정직하게 거부된다. 견적(201)은 자체 120/60 버킷에서 정상 처리.
- burst에서 p95 290→679ms: 로컬 D1 경합 신호. 운영 수치는 별도 측정 필요.
- 로컬 수치 ≠ 운영. 추이 비교용 베이스라인이다.
- 베이스라인은 E2E와 다른 DB·시간에 측정(동일 IP 버킷 공유 금지).
