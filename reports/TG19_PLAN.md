## 1. 기판 결정: D1 마트 + 일 배치 + 플래그 실험 + 규칙 추천

- 웨어하우스는 **별도 infra 없이 D1 집계 마트**(일별 롤업 테이블) —
  "하루 예약 4자리수" 전에는 BigQuery급이 과잉(갭 분석 §12). ETL은
  크론 일 배치(신규 `scheduled` 핸들러 분기 + 어드민 수동 실행).
- 실험 플랫폼: feature_flags + `experiment_assignments`(해시 버킷, 50/50) —
  추천 on/off A/B만 v1.
- 추천 v1: 규칙 기반(함께 본 상품·카테고리 인기·최근 본) — 협업 필터링 아님.

## 2. 범위 (v1)

1. 일 배치 `rollupDaily`: 예약·GMV·검색·전환 롤업 → `fact_daily`
   (신규 마이그레이션 `0052`) + 배치 하트비트 + 실패 시 Sentry + 재시도 1회.
2. 실험: `RECO_V1` 플래그 + 버킷팅 + 노출·클릭 로그 + A/B 지표 API
   (`/api/v1/admin/experiments/reco-v1`: 노출·CTR·예약 전환).
3. 추천 API `GET /api/v1/recommendations?domain=&itemId=` (3 슬롯:
   함께 본·인기·최근 본, 로그인 시 개인화·비로그인 시 전체 인기) +
   상품 상세 UI 슬롯 (user 포털, 44px 터치).
4. PG 스키마 이식 + 체크리스트 0단계에 0052 주의.

## 3. 비목표 (명시)

- 외부 웨어하우스(BigQuery·Snowflake) 없음 — D1 마트 v1.
- ML 추천(행렬 분해·임베딩) 없음 — 규칙 v1 (TG-21에서 고도화).
- 실시간 스트리밍 없음 — 일 배치 (90일 보존 내 재계산 가능).
- 다변수 실험·자동 승자 판정 없음 — 단일 A/B + 수동 판독.

## 5. 레드드릴

1. 빈 날 배치 → 0행 롤업 + 하트비트 ok (E2E tg19a).
2. 플래그 OFF → 추천 API 503 + UI 미노출 (E2E).
3. 버킷 치우침 → 분포 단언(45~55%, 유닛).
