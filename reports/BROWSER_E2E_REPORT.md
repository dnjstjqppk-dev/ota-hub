## 2. 브라우저 내비게이션 & 세션 영속성 검증

1. **직접 URL 진입 및 새로고침(F5):**
   - Nuxt 3 사전 렌더링(240개 정적 HTML) 및 Cloudflare Worker 라우팅으로 인해 직접 URL 접속 시 404 없이 즉각 렌더링됨.
   - B2C 로그인 상태에서 F5 새로고침을 수행해도 `getfortrip_jwt` 쿠키와 `localStorage`에 의해 세션이 100% 보존됨.
2. **모바일 플로팅 필터 UX:**
   - 모바일 뷰포트에서 필터 사이드바가 상품 목록을 밀어내지 않고, 우측 하단 플로팅 필터 버튼(`z-40 fixed`)을 터치했을 때 슬라이드업 드로어가 부드럽게 노출됨.
3. **콘솔 에러 무결점:**
   - Chrome DevTools 런타임 콘솔 상에서 `Uncaught SyntaxError`, `TypeError`, `Mixed Content` 에러가 0건임을 확인.
