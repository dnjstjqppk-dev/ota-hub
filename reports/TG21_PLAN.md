## 1. 기판 결정: 해석 가능한 모델 + 가드레일 + A/B 증명

- ML은 **외부 학습 없이 워커에서 도는 경량 모델**만: 수요 예측(지수평활 +
  요일·시즌 계수), 동적 마크업(예측×재고율, 상·하한 캡). 블랙박스 없음 —
  모든 조정은 `pricing_decisions`에 이유와 함께 기록 (감사 가능).
- 리뷰 LLM·CS 봇은 **Workers AI**(Cloudflare 내장, 외부 키 없음) + 폴백:
  AI 미설정 시 규칙 응답. LLM 출력은 표시 전 금칙어·PII 필터.
- 수용(A/B 증명)은 TG-19 실험 플랫폼으로: 마크업 on/off, 봇 on/off.

## 2. 범위 (v1)

1. 수요 예측: `forecastDemand(도메인·상품·일자)` (지수평활+계수, 마트 기반) +
   어드민 예측 조회 (`/api/v1/admin/forecast`).
2. 동적 마크업: 예측×재고율 → ±15% 캡 + 플래그(`DYNAMIC_MARKUP`) + A/B +
   결정 로그(`pricing_decisions`, 신규 마이그레이션 `0053`).
3. 리뷰 요약: 상품별 리뷰 LLM 요약(주간 배치, 3줄) + 폴백(상위 리뷰 인용).
4. CS 봇: 1:1 문의 1차 응답(FAQ·예약 조회·취소 안내) + 사람 이관(버튼 1개,
   SLA 24h 유지) + 플래그(`CS_BOT`) + A/B(해결율·이관율).
5. PG 스키마 이식 + 체크리스트 0단계에 0053 주의.

## 3. 비목표 (명시)

- 외부 ML 플랫폼(SageMaker·Vertex) 없음 — 워커 내 경량 모델.
- 외부 LLM 키(OpenAI 등) 없음 — Workers AI + 규칙 폴백.
- 무인 CS 없음 — 봇은 1차, 이관은 항상 1클릭 (사람 대체 아님).
- 서지 방지 없음 — 마크업 캡·하한가(#9 WO-OTA) 유지, 폭리 패턴은 감사.

## 5. 레드드릴

1. 마크업 상한 초과 시도 → 캡 + 감사 (유닛).
2. LLM 출력에 PII → 필터 마스킹 (유닛).
3. 봇 오답 신고 → 이관 + 학습 큐 적재 (E2E tg21c).

## 7. 준비도 검토 (2026-11-17 구현 전, 증거 연결)

- 요구 명확성: §2 범위 5항·§4 A1-A5·§5 드릴 3종은 관측 가능하고
  충돌 없음. §3 비목표가 경계를 닫음.
- 정찰 발견 1 (마크업 결정성): 재고·예측은 견적→예약 사이 변하므로
  재계산하면 PRICE_CHANGED가 난다. 견적 시 계산·저장하고 예약
  재검증은 저장값을 재사용한다 (쿠폰·코인 스냅샷과 동일한 원칙).
- 정찰 발견 2 (정산 귀속): 마크업은 플랫폼 몫이라 공급사 기준에서
  제외한다. 원장 분할 + 정산 basis에서 차감하고 COMMISSION에

  컬럼 추가 (가산형). 저널 형상 불변.
- 정찰 발견 3 (하한가): 자사 할인이 하한가를 깨면 클램프 (거부 아님).
